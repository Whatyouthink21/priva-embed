Endpoints

REST / JSON
GET/embed/movie/{id}

Movie iframe by TMDB ID

GET/embed/tv/{id}/{season}/{episode}

TV episode iframe

GET/api/sources/movie/{id}

Resolved movie sources and subtitles

GET/api/sources/tv/{id}/{season}/{episode}

Resolved episode sources and subtitles

GET/api/health

Resolver configuration and connectivity

GET/api/media?token={signed-token}

Signed media delivery · use the URL returned by the API
